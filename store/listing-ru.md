# Описание для магазинов (русский)

## Название
Bitrix _NCC: отключение композитного кеша

## Краткое описание
Включает cookie Bitrix _NCC (BITRIX_SM_NCC=Y), чтобы отключить композитный кеш на текущем сайте при отладке.

## Описание
Отключите композитный кеш 1С-Битрикс для себя одним кликом, не меняя настройки сайта.

Битрикс не использует композитный кеш для запроса с cookie <префикс>_NCC=Y
(BITRIX_SM_NCC=Y при стандартном префиксе): страницы генерирует PHP, и вы видите свои последние изменения.
Остальные посетители по-прежнему получают закешированные страницы.

Возможности:
• Кнопка на панели ставит и убирает BITRIX_SM_NCC=Y для текущего сайта; бейдж «N» показывает, что cookie включена
• Cookie сохраняется: Битрикс удаляет cookie _NCC у неавторизованных посетителей на каждой странице, расширение ставит её снова, пока вы её не выключите
• Cookie только для текущего хоста или для родительского домена со всеми поддоменами
• Своё имя cookie для сайта с другим префиксом (точное имя — COOKIE_NCC в /bitrix/html_pages/.config.php)
• Кнопка «Открыть без композита (?ncc=1)» — для серверов, где композитный кеш отдаёт nginx и cookie не проверяется
• Горячая клавиша Alt+Shift+Y
• Работает с контейнерами Firefox, приватными окнами и режимом инкогнито Chrome (после разрешения в настройках дополнений браузера)
• Поддерживается Firefox для Android (без горячих клавиш)
• Интерфейс на английском, русском и казахском

Расширение не собирает и не отправляет никаких данных. Исходный код: https://github.com/goodprogrammist/BITRIX_SM_NCC
