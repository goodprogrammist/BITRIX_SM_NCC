# Общие инструкции для ИИ-агентов

Этот файл — единый источник проектного контекста для Codex, Google Antigravity, Claude Code и GitHub Copilot. Codex и Antigravity читают `AGENTS.md` напрямую; `CLAUDE.md` и `.github/copilot-instructions.md` подключают его для остальных агентов.

## Работа в проекте

- Перед началом изучи `README.md` (если есть), инструкции проекта и `AI_HANDOFF.md`.
- Проверь `git status`; не перезаписывай и не удаляй чужие изменения.
- Следуй командам сборки и тестирования проекта. Проверяй изменения подходящими тестами и явно сообщай о непроверенном.
- Не запускай разрушающие команды, production-деплой, миграцию или действия с реальными данными без прямого запроса.
- Не помещай токены, пароли, ключи и личные данные в исходники или `AI_HANDOFF.md`.
- Общие правила можно хранить в Git проекта. В репозиториях `gpro/com` настройки агентов исключены из Git и сохраняются через `~/git/sh/backup/NEURO`.

## Передача работы между агентами

- Если в `AI_HANDOFF.md` есть незавершённая задача, сначала сверь её с текущими изменениями и не перезаписывай работу другого агента.
- Для задачи, которую предстоит продолжить в другой сессии, фиксируй в `AI_HANDOFF.md` цель, статус, агента и время, затронутые файлы, решения, следующие шаги и результаты проверок.
- По завершении очисти текущую передачу. Передавая работу в отдельный worktree, помни: незакоммиченные изменения не видны в других worktree; для `gpro/com` локальные файлы агента восстанавливаются из `~/git/sh/backup/NEURO`.

## Chrome на хосте `hp`

Для браузерной автоматизации с установленными расширениями запускай Chrome на Xvfb с обычным профилем пользователя:

```bash
Xvfb :99 -screen 0 1920x1080x24 &
env -u WAYLAND_DISPLAY DISPLAY=:99 google-chrome --ozone-platform=x11 --disable-session-crashed-bubble &
```

Не используй headless и не запускай второй Chrome с тем же профилем: расширения и входы доступны только в обычном профиле `~/.config/google-chrome`. `-u WAYLAND_DISPLAY` и `--ozone-platform=x11` необходимы, чтобы окно осталось на Xvfb. После запуска проверь, что браузерное расширение подключилось.
